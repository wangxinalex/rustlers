# Mutability

## Concept

Mutable bindings with `let mut` and integer arithmetic.

## Task

Implement `add_tax(price)` by adding eight percent tax to the price.

## Expected behavior/output

`add_tax(100)` returns `108`, and the demo prints `108`.

## Hint

Store the price in a mutable variable, then add `price * 8 / 100` to it.

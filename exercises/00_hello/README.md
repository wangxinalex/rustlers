# `00_hello`

## 学习目标

熟悉 Rust 程序的基本形状，练习打印、绑定变量、可变性、类型标注和简单算术。

## 练习顺序

1. `01_print_line`：打印问候语，认识 `fn main` 和 `println!`。
2. `02_variables`：使用 `let` 绑定值并推断基本类型。
3. `03_mutability`：用 `let mut` 修复可变变量示例。
4. `04_types`：添加显式类型标注，完成小额账单计算。

## 前置条件

开始前请先安装 Rust，并确认 `rustc --version` 和 `cargo --version` 可以运行。

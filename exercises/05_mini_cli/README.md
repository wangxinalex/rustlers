# `05_mini_cli`

## 学习目标

把前面学到的字符串、集合、借用和 `Result` 组合起来，完成一个小型标准库命令行工具。

## 练习顺序

1. `01_text_stats`：为字符串计算 `lines`、`words` 和 `bytes` 统计。
2. `02_file_report`：读取文件并输出文本统计，同时报告清晰的用法或错误信息。

## 前置条件

开始前请完成 `04_errors`，并能使用 `cargo test` 检查返回 `Result` 的函数。

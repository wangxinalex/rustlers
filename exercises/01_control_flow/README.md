# `01_control_flow`

## 学习目标

理解 Rust 中表达式会产生值，并练习条件、`for`、`while` 和 `match` 控制流程。

## 练习顺序

1. `01_if_expression`：从 `if` 表达式返回分类结果。
2. `02_for_sum`：用 `for` 循环计算范围总和。
3. `03_while_countdown`：用 `while` 安全倒计时。
4. `04_match_command`：用 `match` 映射命令词，并处理通配分支。

## 前置条件

开始前请完成 `00_hello`，尤其是变量、类型和基本表达式练习。

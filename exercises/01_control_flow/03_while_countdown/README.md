# While countdown

## Concept

Repeating a loop while a condition remains true.

## Task

Use a `while` loop to collect values from `start` down to 1.

## Expected behavior/output

`countdown(3)` returns `[3, 2, 1]`, and the demo prints `[3, 2, 1]`.

## Hint

Keep looping while the current value is greater than zero.

# `02_functions_collections`

## 学习目标

练习函数、集合、字符串、切片和迭代：定义带参数和返回值的函数，并用 `Vec` 和 `String` 处理集合与文本数据。

## 练习顺序

1. `01_parameters`：定义带参数和返回值的函数。
2. `02_slice_sum`：遍历切片并计算总和。
3. `03_word_count`：用空白分割统计字符串中的单词。
4. `04_shopping_total`：根据集合数据计算购物总价。
5. `05_unicode_lengths`：区分 Unicode 标量值与 UTF-8 字节长度。

## 前置条件

开始前请完成 `01_control_flow`，并能读懂函数调用和循环。

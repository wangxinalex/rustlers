# `02_functions_collections`

## 学习目标

练习定义带参数和返回值的函数，并用 `Vec`、`String`、切片和迭代处理集合数据。

## 练习顺序

1. `01_parameters`：定义带参数和返回值的函数。
2. `02_push_vec`：向 `Vec` 添加项目并报告长度。
3. `03_slice_sum`：不取得所有权地遍历切片。
4. `04_word_count`：用空白分割统计字符串中的单词。
5. `05_shopping_total`：根据集合数据计算购物总价。

## 前置条件

开始前请完成 `01_control_flow`，并能读懂函数调用和循环。

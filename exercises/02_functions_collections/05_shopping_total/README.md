# Shopping total

## Concept

Summing a slice and applying an integer percentage discount.

## Task

Implement `shopping_total(prices, discount_percent)` so it returns the discounted total.

## Expected behavior/output

`shopping_total(&[100, 50], 10)` returns `135`, and the demo prints `135`.

## Hint

Sum the prices first, then multiply by the remaining percentage and divide by `100`.
